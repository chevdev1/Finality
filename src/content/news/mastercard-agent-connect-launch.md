**Главное**
- 9 сентября Mastercard запустила Agent Connect — единую интеграцию для продавцов, ИИ-агентов, платформ и провайдеров платежей.
- Стартовая сеть работает в США и включает такие компании, как Global Payments, Samsung, Trip.com, Nexi и Vodafone Egypt.
- Agent Connect — часть более широкого Mastercard Agent Suite, куда входит и партнёрство с Anthropic для интеграции моделей Claude.

## Что решает Agent Connect

Agent Connect даёт продавцам, ИИ-агентам, платформам для шопинга и платёжным провайдерам одну точку интеграции вместо отдельного подключения к каждой ИИ-платформе. Через неё продавец получает единый путь для показа товаров, сборки корзины и проведения оплаты с подтверждением клиента — независимо от того, на какой ИИ-платформе покупатель начал покупку.

## Кто уже подключился

Стартовая сеть работает в США. Среди первых партнёров — Bemobi, Getnet, Glance, Global Payments, Planet, Network International, Nexi, Samsung, Trip.com, Vodafone Egypt, Wizard и Wompi.

## Как это связано с Mastercard Agent Suite

Agent Connect дополняет более ранний Mastercard Agent Suite — набор сервисов для внедрения агентного ИИ в повседневные операции бизнеса. В его рамках Mastercard также партнёрится с Anthropic, добавляя модели Claude для постпродажной поддержки — например, отслеживания заказов и оформления возвратов, — и продолжает работу с другими ИИ-компаниями, включая OpenAI, над сценариями покупок, авторизованных продавцом через агента.
