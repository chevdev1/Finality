**Главное**
- 20 августа Binance запустила Agent OS — платформу для любого ИИ-агента, совместимого с Model Context Protocol.
- На старте поддерживаются Claude, Claude Code, Codex, ChatGPT, Cursor и VS Code.
- Авторизованный агент торгует через изолированный суб-аккаунт без прав на вывод средств на внешние кошельки.

## Что даёт Agent OS

Agent OS объединяет в одной платформе API биржи, отдельный хаб агентских кошельков, платёжный слой [x402](/glossary/#x402-protocol) для расчётов между агентами и маркетплейс навыков. В основе — Model Context Protocol, открытый стандарт от Anthropic, который даёт совместимым ИИ-приложениям единый способ подключаться к внешним инструментам. Именно поэтому список поддерживаемых агентов на старте включает конкретные продукты: Claude, Claude Code, Codex, ChatGPT, Cursor и VS Code.

## Где проходит граница безопасности

Ключевой защитный механизм — изоляция: авторизованный агент получает доступ к рыночным данным и может исполнять сделки на споте, марже, в конвертации и на фьючерсах, но работает через суб-аккаунт без прав на вывод средств за пределы биржи. Формально это ограничивает потенциальный ущерб от ошибки или взлома агента рамками одного суб-аккаунта.

## Почему защита «тоньше, чем кажется»

Отраслевые критики отмечают, что ограничение на вывод средств не устраняет риск полностью: агент с доступом к фьючерсам и марже всё ещё может нанести реальный финансовый ущерб самому суб-аккаунту через неудачные или манипулятивные сделки, даже не имея возможности вывести средства наружу. Запуск Binance идёт на фоне более широкой тенденции — ИИ-боты уже обеспечивают, по оценкам, 58% всего объёма торгов на крипторынке, — и добавляет крупнейшую по объёму биржу в список площадок, институционализирующих агентскую торговлю, а не просто терпящих её.
